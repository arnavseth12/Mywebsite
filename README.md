# My Website 🚀

A traditional scrolling portfolio combined with a highly immersive, interactive terminal interface. Designed to showcase work, bio, and experience while offering an engaging, retro-futuristic user experience.

---

## 🌟 Key Features

* **Dual-Mode Layout**: Seamless blending of a traditional scrolling portfolio with a functional terminal command line.
* **Immersive Themes**: Switch between multiple visual styles, including a green "Matrix Hacker" mode.
* **Hidden Easter Eggs**: Uncover secret commands and built-in retro minigames.
* **Fully Responsive**: Optimized to deliver a seamless experience across desktop and mobile viewports.

---

## 🛠️ Built With

* **HTML5**: Structured for semantic accessibility.
* **CSS3**: Custom styling, responsive layouts, and smooth terminal animations.
* **Vanilla JavaScript**: Lightweight, dependency-free interactive logic and terminal command processing.

---

## 📁 Sections Included

* **Bio**: A personal introduction and overview of core skills.
* **Work & Projects**: A showcase of key development work with source links.
* **Experience**: A detailed timeline of professional history and achievements.
* **Terminal Interface**: An interactive command-line environment for deeper exploration.
